# 二、项目开发规范

## 代码规范

- 代码格式化：依据项目自带 \.clang\-format 执行。

- 风格指南：除以上两条自定义规则外，其余代码风格遵循  [Google 开源项目风格指南](https://zh-google-styleguide.readthedocs.io/en/latest/)。

- 注释要求：必须使用英文注释。

- 禁止操作：禁止使用 `merge` 操作，统一使用 `rebase` 或 `squash`。

- 包含规范：遵循 IWYU（Include \(only and all\) What You Use）原则。

## 开发流程

- commit message：采用 [约定式提交规范](https://www.conventionalcommits.org/zh-hans/v1.0.0/#%E6%A6%82%E8%BF%B0)。

- 分支与 pr 流程：

    - master 为开发分支，开发者向 master 提交 pr；

    - PR Reviewer：@段晨婕及对应项目导师。
